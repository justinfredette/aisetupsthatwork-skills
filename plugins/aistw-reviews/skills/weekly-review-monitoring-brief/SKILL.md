# One Weekly Brief for Reviews Across Google, Yelp, and Facebook

## When to use

Busy owners who check reviews "when they remember," which means a 1-star sits for six weeks while regulars read it.

## Steps

1. Set a Google Alert for your exact business name plus "review" to catch mentions outside the big platforms.
2. Pick one day and time each week. Put it on the calendar like an appointment.
3. Open Google, Yelp, and Facebook reviews. List every new review since last week with rating and one-line gist.
4. Triage: 1 to 2 stars first, then questions, then positive reviews.
5. Draft replies for all of them in one chat session, then post each reply yourself.
6. Log any issue mentioned twice into a running list. That list feeds your monthly fix-it session.

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
Turn this week's new reviews into a monitoring brief for my business, plus reply drafts. I post everything myself.

Business: [name]
Week of: [date]

New reviews:
[paste each with platform, rating, text, date]

Return:
1. Brief: total new reviews, average rating this week, any rating change vs last week.
2. Triage list: which need replies first and why.
3. One draft reply per review, under 60 words, in my voice: [describe tone].
4. Issues mentioned more than once, quoted briefly.

Rules:
- Flag anything that looks fake or violates policy; do not draft a reply for those, note them for reporting.
- Never invent facts about my business.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- Google Alerts misses plenty. It is a net, not a guarantee. The manual sweep still matters.
- Letting it slide for a month turns a 15-minute habit into a 2-hour dread pile.
- Do not reply to obvious fakes with a full apology. Report first, reply briefly or not at all.
- One person should own the brief. "We all check" means nobody checks.
