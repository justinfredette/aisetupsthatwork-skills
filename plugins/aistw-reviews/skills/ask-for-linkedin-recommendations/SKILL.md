# Ask for LinkedIn Recommendations (and Get Yeses)

## When to use

Job seekers, freelancers, and career changers with an empty recommendations section who keep meaning to ask.

## Steps

1. List 3 to 5 people who directly saw your work: a manager, a close colleague, a happy client. Not acquaintances.
2. For each person, note one specific project and one skill you want highlighted.
3. Ask AI for a short personalized message per person: greeting, the shared project, the specific ask, an easy out.
4. Edit each message so it sounds like you. Never send LinkedIn’s default request text.
5. Send from LinkedIn’s "Ask to be recommended" flow or by direct message, whichever fits the relationship.
6. If no reply in a week, send one polite follow-up. Then let it go.

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
Write LinkedIn recommendation request messages for me. Short, warm, specific. I will send them myself.

My name: [name]
My role: [title]

Person 1:
- Name and relationship: [e.g. former manager at Acme]
- Project we worked on: [specific project]
- Skill to highlight: [e.g. leading the migration]

[repeat for each person]

Rules:
- Under 100 words per message.
- Name the specific project so they remember the work.
- Give them an easy out ("no pressure if timing is bad").
- Offer to reciprocate where it fits.
- Never use LinkedIn's generic default text.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- Generic asks get ignored. If you would not recognize the project from the message, rewrite it.
- Do not ask people who barely know your work. A thin recommendation hurts more than none.
- LinkedIn caps how you can message non-connections. Warm relationships first.
- Never write the recommendation yourself and ask them to paste it, unless they ask you to draft one.
