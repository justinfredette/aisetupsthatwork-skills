# Measure the real time AI drafts save

## When to use

Owners and managers who suspect AI drafts are just moving work to whoever checks them.

## Steps

1. Pick one repeat job, such as quotes, job posts or customer replies.
2. For 5 tasks done the old way, log minutes for drafting, review and fixes.
3. For 5 tasks with AI, log the same, including who reviewed.
4. Paste both into the prompt below.
5. If review grew, improve the prompt or add a checklist so drafts need fewer fixes, then measure again.
6. Use the honest number when deciding where AI goes next.

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
Compare these timings. Use only my numbers.

Old way (per task: drafting min, review min, fixes min, reviewer role): [PASTE 5]
With AI (same columns): [PASTE 5]

1. Average total minutes per task, old versus AI
2. Where the time moved, and to whom
3. Whether the business is actually faster
4. The single change most likely to cut review time
Do not round in AI's favor.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- Timing only the drafting step.
- Comparing easy AI tasks with hard old ones.
- Skipping rework that shows up days later.
