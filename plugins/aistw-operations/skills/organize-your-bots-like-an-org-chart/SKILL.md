# Organize your bots like an org chart

## When to use

Owners with several bots that overlap, step on each other or leave jobs half done.

## Steps

1. List every bot and what it actually does today.
2. Run the prompt below to get a one-page org chart with one coordinator and specialists.
3. Give each specialist one job, its tools, and what done looks like.
4. Tell the coordinator how to hand off: the task, the deadline, and where the result goes.
5. Put yourself at the top: anything that sends, posts, pays or changes records comes to you.
6. Start with one working job end to end before adding more roles. Grok Bot group owners running many bots said the same.

## What to ask the user for

- LIST
- JOBS

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
Turn my bots into a simple org chart. Use only my list.

Bots and what each does today: [LIST]
What I want covered: [JOBS]

1. One coordinator bot: what it accepts, how it hands off, how it reports to me.
2. Specialists: one job each, tools, what done looks like.
3. Overlaps to remove and gaps with no owner.
4. The approval line: what always comes to me.
Keep it to one page.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- Two bots doing the same job differently.
- A coordinator that tries to do everything.
- Adding roles before one job works end to end.
