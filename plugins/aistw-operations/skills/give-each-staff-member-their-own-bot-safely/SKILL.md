# Give each staff member their own bot safely

## When to use

Owners giving bots to a team, especially after a bot signed in with another person's account.

## Steps

1. Decide the starter set every person gets: the rulebook, approvals, and 1 to 3 standard routines.
2. Give each person their own bot and computer or workspace. xAI notes the bot's computer shares its browser, files and credentials, so shared machines mean shared logins.
3. Each person signs in their own accounts. Nobody signs in for someone else.
4. Use the prompt below to write the starter rulebook once.
5. Let each person add routines for their own job, within the rulebook.
6. Monthly: list which accounts each bot can reach and remove anything that is not that person's.

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
Write a starter rulebook every staff member's bot gets. Use only my rules.

Our business: [ONE LINE]
What any staff bot may do: [LIST]
What needs the person's approval: [LIST]
What no staff bot may ever do: [e.g. use another person's login, touch payroll, pay anything]

Under 250 words, 4 headings: May do, Ask first, Never, If unsure. Add the rule: only use the accounts of the person you work for.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- One shared bot computer for the whole team.
- Signing in a teammate's account to get a bot working.
- No list of what each bot can reach.
