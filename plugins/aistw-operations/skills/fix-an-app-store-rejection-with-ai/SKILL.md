# Fix an App Store rejection with AI

## When to use

First-time app builders, often building with AI tools, whose app keeps getting rejected and who cannot tell what Apple actually wants.

## Steps

1. Copy the whole rejection message, including the guideline number, such as 2.1 or 4.3.
2. Open Apple's App Store Review Guidelines and copy the text of that numbered rule.
3. Paste both into the prompt below with a short description of your app.
4. Make the smallest changes that address the rule. Do not argue with the reviewer in the app itself.
5. Edit the drafted reply so every statement is true, then send it from App Store Connect.
6. Keep a log of each rejection, the rule and the fix. One founder reported 6 rejections before approval; a log stops repeats.

## What to ask the user for

- PASTE
- PASTE FROM APPLE'S PAGE
- DESCRIPTION

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
My app was rejected from the App Store. Use only what I paste.

Rejection message: [PASTE]
Guideline text for the number cited: [PASTE FROM APPLE'S PAGE]
What my app does, in 3 lines: [DESCRIPTION]

1. Explain in plain words what App Review is asking for.
2. List the smallest changes that would address it, most likely first.
3. Draft a reply to App Review under 120 words: polite, factual, says what changed. No arguing, no promises I did not give.
If the message is unclear, list the questions I should ask App Review instead of guessing.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- Resubmitting without changing anything.
- Arguing in the reply instead of fixing.
- Guessing the rule instead of reading the guideline text.
