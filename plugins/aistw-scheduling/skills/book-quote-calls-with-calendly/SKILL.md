# Book quote calls with Calendly

## When to use

Service businesses that book estimates or consultations. Once the page is live, people book real time on your calendar, so set availability and buffers before you share the link.

## Steps

1. Connect your work calendar. Calendly says connecting calendars keeps availability in sync and avoids double bookings, and it works with Google, Outlook and Microsoft Office.
2. Set the hours you actually take calls. Calendly lists preferred hours, daily meeting limits and built-in buffers as availability options.
3. Create one event type called Quote Call, 20 or 30 minutes, with 2 or 3 intake questions: what the job is, where it is, and a phone number.
4. Run the prompt below for the event description and reminder emails, then paste them in.
5. Turn on reminder emails in the Workflows section. Calendly describes automations for meeting reminders and follow-ups.
6. Book a test call yourself from the live link and check the reminders arrive.
7. Put the link in your email signature, texts and social profiles.

## What to ask the user for

- NAME, what you do, area you cover
- 20 or 30

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
Write the text for my booking page.

Business: [NAME, what you do, area you cover]
Event: a [20 or 30]-minute quote call
What callers should bring: [photos, address, measurements, or nothing]

Write:
- A 2-sentence event description that says what the call covers
- 3 intake questions
- A reminder email for 24 hours before, under 60 words
- A reminder text for 2 hours before, under 160 characters

Rules:
- Use only the facts I gave you. No invented promises about prices or timing.
- Show me the text first. Do not send anything.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- A forgotten personal calendar invites double bookings. Connect every calendar you use.
- No buffers means back-to-back calls that run late into each other.
- Intake questions that ask too much cut bookings. Keep it to 2 or 3.
