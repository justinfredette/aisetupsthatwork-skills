# Etsy listing titles, tags, and descriptions with AI

## When to use

Etsy sellers who want their listings to show up in Etsy search without guessing at keywords.

## Steps

1. List the facts: item type, materials, size, colors, and who buys it. No marketing fluff yet.
2. Draft the title first: start with the item type, then key traits, most important keywords first, about 15 words or fewer.
3. Generate 13 tags as varied multi-word phrases shoppers would type. Skip phrases your categories and attributes already cover.
4. Write the description with relevant keywords in the first few sentences, then the details a buyer needs.
5. Check for keyword stuffing and repeated terms. If a phrase appears in the title, it does not need to be a tag.
6. Use all 10 image slots. The first photo drives clicks from search results.

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
I sell on Etsy. My product: [DESCRIBE ITEM, MATERIALS, SIZE, COLORS, WHO IT IS FOR]. Draft: 1) a title of 15 words or fewer, starting with the item type, most important keywords first, no repeated terms; 2) exactly 13 tags as varied multi-word phrases a shopper would search, no keyword stuffing; 3) a description with relevant keywords worked naturally into the first two sentences, then buyer details. Show me the drafts before I publish.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- AI invents keyword trends. Check tag ideas against what real listings in your niche actually use.
- Keyword stuffing hurts readability and can work against you. One natural use per phrase is enough.
- Etsy uses description words in ranking, but buyers read them too. Write for the human first.
