# Find warm leads from job posts with AI

## When to use

Freelancers, agencies and service businesses that sell to other companies, such as operations, bookkeeping, marketing, dispatch or IT help.

## Steps

1. List 3 to 5 roles your service can partly cover, like dispatcher, operations manager or bookkeeper.
2. Search those roles on a job board. LinkedIn's help center describes filtering job results by date posted, so you can sort out brand-new posts from ones that have been up longer.
3. Open a listing and copy the responsibilities section. That list shows what the team is struggling with.
4. Paste it into the prompt below with what you actually offer and results you can prove.
5. Check the draft. The FTC says advertising claims must be truthful, not deceptive and evidence-based, so delete any number or result you cannot back up.
6. Send each message yourself to the right person, log it, and follow up once. Browse and send by hand; don't scrape the site.

## What to ask the user for

- ONE SENTENCE
- E.G. CUT DISPATCH CALLS FOR A 12-PERSON HVAC SHOP

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
Here is a job listing. Help me write an honest first message to the company.

Listing: [PASTE TITLE, COMPANY SIZE IF SHOWN, DATE POSTED, RESPONSIBILITIES]
What I offer: [ONE SENTENCE]
Results I can prove (or 'none yet'): [E.G. CUT DISPATCH CALLS FOR A 12-PERSON HVAC SHOP]

1. List the 3 most likely problems behind this listing, each tied to a line in the responsibilities.
2. Write a 4-sentence first message that mentions their specific situation, offers one useful idea, and asks for a short call.

Rules: use only the facts above. Do not invent results, clients or numbers. If I have no proven results, offer a small first step instead.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- Inventing a case study or percentage to sound credible. Only claim what you can prove.
- Pitching the job seeker role itself; you are offering help, not applying.
- Sending the same message to every listing.
