# Find Unclaimed Money in Your Name with ChatGPT

## When to use

For anyone who has moved, changed names, closed old bank accounts, or handled a relative's estate and wonders whether a state is holding money for them.

## Steps

1. Write down each state you've lived, worked, or banked in, plus every version of your name. Add any business names you've owned.
2. Paste that list into ChatGPT or Claude with the prompt below. It uses web search to find each state's official unclaimed property site and flags any state it can't confirm on MissingMoney.com.
3. Run the MissingMoney.com search yourself for each name variant. Then search each flagged state on its own site.
4. Check the federal lists USA.gov points to if they fit you: unpaid wages, old pensions, matured savings bonds, and deposits from failed banks.
5. Paste the matches you find (holder, amount shown, state) back into the chat. Leave out your Social Security number. Ask for a claim checklist for each state.
6. File each claim yourself on the official state site. Searching and claiming there is free.
7. If a finder company offers to recover the money for a percentage, remember the same claim is free on the state site. Check with your state's office before you sign anything.

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
Help me search for unclaimed money in my name. Don't file anything or contact anyone for me.

My names (include maiden names, nicknames, misspellings): [names]
States I've lived, worked, or banked in, with rough years: [states and years]
Businesses I've owned, if any: [business names]

1. Use web search to find the official government unclaimed property website for each state on my list. Only list official state sites and MissingMoney.com.
2. Tell me which of my states you can't confirm are searchable on MissingMoney.com, so I search those directly.
3. Give me a short search checklist: each name variant to try, and on which site.
4. When I paste matches back, make a table: state, holder, amount shown, what proof that state's claim page asks for, and the official link to file.

Rules: If you can't confirm a site is official, say so. Don't guess amounts or invent matches. Never ask for my Social Security number.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- ChatGPT or Claude may not be able to open or search the state databases, so plan to run each search yourself and paste the results back.
- MissingMoney.com covers most states, not all. Search any state the plan can't confirm on that state's own site.
- Each state sets its own proof of identity and ownership, so a claim can stall until you send the right document.
