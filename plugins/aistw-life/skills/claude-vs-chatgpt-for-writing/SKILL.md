# Claude vs ChatGPT for everyday writing (honest comparison)

## When to use

People juggling both tabs who want a simple decision tree before they paste another draft.

## Steps

1. Name the job: short email, long report, template you reuse, or scheduled reminder.
2. Read the comparison table on this page. Features only, no speed scores.
3. Open the matching product (ChatGPT Project/Task or Claude Project/Artifact).
4. Paste the prompt below with facts; forbid invented quotes and sends.
5. You edit voice and send from your apps.

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
Help me draft: [describe document]
Audience: [who]
Tone: [warm/professional/plain]
Facts I provide (only use these):
[paste]

Rules:
- Do not invent names, metrics, or quotes.
- Mark uncertainties with [verify].
- Draft only: I send/publish manually.
Return: outline, then full draft, then 3-bullet checklist of what I should verify.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- Feature names change. Re-read help docs when a button moves.
- Neither tool knows your inbox unless you connect integrations they explicitly support.
- Do not paste regulated data (HIPAA, kids’ IDs) into either without policy review.
