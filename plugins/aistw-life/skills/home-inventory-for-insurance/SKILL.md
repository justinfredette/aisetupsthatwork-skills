# Home Inventory for Insurance (Photo Walkthrough in an Afternoon)

## When to use

Homeowners and renters who have been meaning to document their stuff for years. If you could not list your belongings from memory after a fire, this is for you.

## Steps

1. Tell the AI your home type and room count so the plan matches your space.
2. Ask for a room-by-room walkthrough order, starting with high-value rooms.
3. Video each room slowly, narrating as you go. Open every closet, drawer, and cabinet.
4. Photograph high-value items up close: serial numbers, brand labels, receipts in the same shot.
5. Fill in the AI’s spreadsheet template for big-ticket items: description, brand, model, purchase date, price.
6. Save everything in two places: cloud plus one more copy outside your home.
7. Set a yearly reminder to update it after big purchases.

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
Help me build a home inventory for insurance. Make it doable in one afternoon.

Home: [e.g. "3-bed house" / "2-bed apartment, renting"]
Rooms: [list them, e.g. "kitchen, living room, 3 bedrooms, garage, basement"]
High-value items I know about: [e.g. "MacBook Pro, wedding ring, power tools, Peloton"]
Insurance: [homeowners / renters / none yet]

Rules:
- Give me a room-by-room walkthrough order, highest value first.
- For each room, list exactly what to photograph and what to write down.
- Include a spreadsheet template with columns: item, brand/model, serial number, purchase date, price, photo filename.
- Tell me what needs special coverage (jewelry, art, firearms, collectibles) and to ask my insurer.
- Tell me where to store the inventory so it survives a fire or theft at this address.
- You plan and organize. I take the photos and fill in the values.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- Trying to be perfect stalls the project. A basic inventory today beats a perfect one you never finish.
- Storing the only copy inside the house defeats the purpose. Cloud plus off-site, no exceptions.
- Forgetting to update after big purchases. Tie the update to something annual, like tax time.
