# Write holiday cards with Claude

## When to use

Claude users with cards or thank-you notes to write who want drafts that sound like them. Anthropic says Projects are available to all users; Free can make up to five.

## Steps

1. Make a Project called Holiday cards. Add 3 to 5 cards, notes or texts you wrote yourself to the project knowledge, as files or pasted text.
2. Paste the first part of the prompt into the project instructions. Anthropic says project instructions tailor Claude's replies in that Project, for example to a more formal tone.
3. Make the list: who each card is for, how you know them, and one real detail from this year. For thank-you notes, add the gift.
4. Start a chat in the Project and paste the second part of the prompt with the list.
5. Read each draft out loud. Cut anything you would never say, and any detail that is not on your list.
6. Copy the drafts into your cards, or write them out by hand. Nothing is sent from Claude.

## What to ask the user for

- PERSON OR RELATIONSHIP

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
PROJECT INSTRUCTIONS:
You draft holiday cards and thank-you notes in my voice. Match the length, tone, greetings and sign-offs in the samples in this Project's knowledge. Use only details I give you. Never invent memories, plans or news. No rhymes unless my samples rhyme, and no stock lines like "wishing you a magical season". Draft only; I write and send everything myself.

CHAT PROMPT:
Draft one message for each person below. Card type: [holiday card / thank-you note]. Length: [match my samples / 2 to 3 sentences].

[PERSON OR RELATIONSHIP] | how I know them: [...] | one detail from this year: [...] | gift, for thank-you notes: [...]
[one line per person]

After the drafts, list anyone whose detail was too thin to write something specific, so I can add more.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- Every card opens the same way. Ask Claude to vary the first line across the stack.
- A draft adds a wish or plan you never mentioned. Delete it; the instructions say to use only your details.
