# Writing Difficult Texts: Boundaries and Apologies That Sound Like You

## When to use

Anyone staring at a blank text box dreading a conversation: apologizing to a friend, telling family no, or pushing back on a coworker politely.

## Steps

1. Write down what happened in plain facts, no spin. What you did, what they did, what you want now.
2. Decide the message type: apology, boundary, feedback, or decline.
3. Tell the AI the relationship and the tone: warm but firm, professional, brief.
4. Get the draft, then read it out loud. If it does not sound like you, it is not done.
5. Rewrite at least 30% in your own words. Add one specific detail only you would know.
6. For serious apologies, consider calling instead. A text carries minor repairs, not major ones.
7. Send it yourself. Never let an agent send personal messages for you.

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
Help me draft a difficult message. I will rewrite it in my own words before sending.

Situation: [what happened, plain facts]
Message type: [apology / boundary / feedback / declining]
Recipient: [e.g. "close friend" / "my manager" / "my mother-in-law"]
My goal: [e.g. "take responsibility without groveling" / "say no to hosting Thanksgiving firmly"]
Tone: [e.g. "warm but firm" / "professional and brief" / "honest, not harsh"]
Length: [text message / short email]

Rules:
- Apologies must name what I did wrong specifically. No "sorry if you felt" non-apologies.
- Boundaries must be clear about what I will and will not do, without over-explaining.
- Keep it short. Long messages dilute the point.
- Match the channel to the seriousness: tell me if this deserves a call instead.
- Draft only. I send everything myself after rewriting.
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- Sending the draft as-is. Apology guides specifically warn that unedited AI apologies read as insincere.
- The AI may soften your boundary into meaninglessness. Check that the “no” survived the draft.
- Using text for something that needs a voice. If the harm is serious, the draft should become talking points for a call.
