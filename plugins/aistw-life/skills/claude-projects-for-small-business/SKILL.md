# Claude Projects for small business repeat work

## When to use

Owners who repeat the same voice and policies across email, listings, and hiring every week.

## Steps

1. Create a Claude Project; upload or paste brand voice, policies, and services list.
2. Add custom instructions: draft-only, no sends, cite when unsure.
3. For each job type, open the Project and run the prompt below with fresh facts.
4. Copy outputs into Gmail, Google Business Profile, or your ATS. You publish.
5. Refresh Project files when pricing or services change.

## Prompt

Fill the [BRACKETED] parts with the user, then follow this prompt:

```
You are my small-business writing assistant inside this Project. Use only facts from Project files and my message.

Job today: [review reply / job description / customer update / other]
Facts for this draft:
[paste specifics]

Rules:
- Match our tone examples in the Project.
- Do not invent discounts, licenses, or guarantees.
- Draft only: I send, publish, or spend manually.
- Flag missing info in [brackets].
```

## Guardrails

- Draft first and show the user. Never send, post, pay, book, cancel or delete without the user's explicit approval of that exact action.
- Use only facts the user gives you or that you can cite. If something is missing, ask instead of guessing.

## Common snags

- Stale Project files cause wrong pricing. Date your uploads.
- Do not upload customer PII you are not allowed to store in cloud AI.
- Projects do not replace a CRM. Copy drafts back to your system.
