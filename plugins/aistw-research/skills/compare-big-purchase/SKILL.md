# Compare a big purchase

## When to use
Use this when I'm deciding on something that costs enough to research: a laptop, TV, appliance, mattress, phone, car seat, or similar. Use it when I ask "which one should I buy" or "compare these."

## What you need from me
If anything below is missing, ask for all of it in one message, then wait. If I've already given everything, skip asking and start.
1. What I'm buying (the product category).
2. My budget, as a top number or a range.
3. Three to five must-haves (for example: size, battery life, warranty, noise level, fits in a space this big).
4. Anything I've already ruled out, and any models I'm already looking at.
5. Who else has a say, if anyone. Add a "their veto" row to the table if so. If I say no one, leave the veto row out.

No accounts or logins are needed. If you can browse the web, use it. If you can't, say so at the top and mark every price "not checked live."

## Steps
1. Pick three finalists that fit the budget and the must-haves. If I named models, include them unless they clearly fail a must-have. If one fails, say which must-have it fails.
2. For each finalist, find:
   - the current price range, with the store or source and the date you checked
   - the specs that match my must-haves, from the maker's spec page when it lists the spec. If it doesn't, or doesn't say how it was measured (for example, which mode a dB figure is for), use a named review's measurement and say so.
   - up to two reviews that show their own test method or measurements. Prefer non-affiliate sources. If the only ones you find use affiliate links, use them but label them "(affiliate links)". If you find fewer than two, say so.
3. Build one comparison table: a row for each must-have, a column for each finalist, plus rows for price, warranty (from the maker's page), and return window (from the store you got the price from). Write "not found" if missing, and add both to the Check before you buy list.
4. Under the table, write the main tradeoff between the finalists in two or three sentences. For example: "A is cheaper but louder. C is quieter but costs $120 more."
5. Don't pick a winner unless I ask. If I ask, give your pick and the one reason it beats the other two on my must-haves.

## Check your work before you answer
- Every price has a source and a date. If you couldn't find a price, write "not found." Don't estimate.
- Every spec in the table comes from the maker's page or a named review. If two sources disagree, show both.
- Each finalist has a model name or number specific enough that I can search for it.
- Nothing in the table is a guess. Mark anything you're unsure of with "(check this)."
- For a yes/no feature the maker doesn't state, write "not stated" rather than guessing.
- If I ask you to keep it quick, do as many lookups as you can and mark the rest "not checked."

## What to give me
1. The comparison table.
2. The tradeoff note.
3. A source list with links: maker spec pages first, then reviews.
4. A "Check before you buy" list of two to four things to confirm on the store page, such as the exact model number, the return window, and whether the price includes shipping.

If you can save files, save it as "[Product] comparison, [today's date]" and tell me where. If you can't, tell me to copy it somewhere I'll find it.

## What needs my OK
- Never buy, reserve, add to cart, or start a checkout.
- Never sign up for an account, a price alert, or a newsletter for me.
- Never share my budget or my details with a store or a seller.
